# 漢末群雄互動地圖 · 180–230 年

以現代中國地圖為底圖，透過年份滑桿、播放及地區選擇，探索漢末至三國初期主要勢力變化。繁體中文介面，可於手機或電腦使用。

## 使用

GitHub Pages 從 main 分支根目錄發佈。亦可下載 index.html，直接用瀏覽器離線開啟；地圖、資料、樣式及 D3 已內嵌，無須 ChatGPT 登入。

## 閱讀限制

這是概覽示意圖，不是精確古代疆界復原。採用現代地級行政區配合主要歷史區域與時間節點，近似呈現主要勢力；年度顯示以年末局勢概括，爭奪及混合地區另有標示。現代底圖不表示古代勢力統治整個現代中國。

歷史骨架參照《三國志》；《火鳳燎原》僅為閱讀背景，並非漫畫官方勢力地圖。參考資料連結列於網頁內。

## 技術

單一靜態 HTML，內嵌 D3 與地圖資料。現代行政區底圖來自 DataV；D3 使用其原有 ISC 授權。
